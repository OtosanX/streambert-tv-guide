Phone install

Fire OS and Android TV

Use an iPhone or Android phone and the same home network as your TV. On a Fire TV, check Settings → My Fire TV → About. If it says Vega OS, use the Vega section.

Download phone kit APK only
  1. Save the APK to your phone. If you downloaded the kit, extract it first. Keep the APK in Files or Downloads.
  2. Enable debugging on your TV. For Fire OS, open My Fire TV → Developer Options → ADB Debugging. If the menu is hidden, highlight the device name under About, press Select seven times, then go Back. On Android TV or Google TV, look for Network or Wireless Debugging instead.
  3. Connect from atvTools. Get it on iPhone or Android. Select your TV and accept the debugging prompt. If it doesn’t appear, enter the TV’s network address in the app.
  4. Send the APK. In atvTools, choose Tools → Install and select the APK. Open Streambert from your TV’s apps list, then follow TMDB setup. Turn debugging off when you’re done.

The APK was checked on NVIDIA Shield. Fire OS playback still needs a device test. The iPhone phone tool is a paid app. Amazon’s Fire TV instructions

Developer preview

Roku TV

The Roku preview can browse and search TMDB and play direct HTTPS HLS or MP4 links. Streambert’s embedded web players are unavailable on Roku. The package compiled successfully. Older Roku models still need testing.

Download Roku ZIP Read the Roku guide
  1. Enable the installer. With the Roku remote, press Home three times, Up twice, then Right, Left, Right, Left, Right. Note the address shown, enable the installer, and set a developer password.
  2. Open the address on your phone. Stay on the same network. Sign in as rokudev using the password you chose.
  3. Upload the ZIP as-is. Tap Upload, choose the original Roku ZIP, then tap Install. Roku has one developer-app slot, so this replaces any previously sideloaded preview.

Set up TMDB once

TMDB provides titles, artwork, and search results. The app keeps its setup steps on the TV until your token is accepted.

  1. Scan the QR or open TMDB API settings on your phone.
  2. Sign in, request a key if needed, then copy the long API Read Access Token.
  3. On Fire OS or Android TV, select the token field and paste it with the atvTools phone keyboard. Then select Save and continue on the TV.

Troubleshooting

My phone can’t find the TV

Check that both devices are on the same home network. Guest networks can isolate devices. Confirm debugging is on and try entering the TV’s network address directly.

The TV says the file can’t be installed

Check the TV’s operating system and use its matching file. Fire OS needs the extracted APK. Roku’s developer installer needs the original Roku ZIP. If Android reports a signing conflict, save your settings before removing the older copy.
