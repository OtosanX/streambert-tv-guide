Android TV and Google TV

Use this section for a TV or streaming box that runs Android TV or Google TV. The shared APK has Fire OS in its filename. Next-episode autoplay in the regular player was confirmed on NVIDIA Shield.

Download APK and both guides Download APK only Read the Android TV checklist

Install free with the TV remote

  1. On the TV, install Downloader by AFTVnews from Google Play if available. Open it, enter otosanx.github.io/streambert-tv-guide/ in its address field, then choose Install on Android TV → Download APK only on the guide.
  2. Open the downloaded APK. If asked, open the settings prompt and allow Install unknown apps for Downloader. Return to Downloader and choose Install. Afterward, you can turn that permission off.
  3. Open Streambert from Apps or Settings → Apps → See all apps → Streambert → Open, then follow the free TMDB setup.
Install free from a Windows, Mac, or Linux computer

Use a computer on the same network and install Google’s Platform-Tools. Open a terminal in the Platform-Tools folder and put the APK there. On Windows PowerShell, use .\adb in place of adb. On macOS or Linux, use ./adb if ADB is outside your PATH.

  1. On the TV, go to Settings → System → About on Google TV or Settings → Device Preferences → About on Android TV. Highlight Android TV OS build or Build and press the center button seven times. Go back and open Developer options. Enable Wireless debugging or Network debugging.
  2. For Wireless debugging, open Pair device with pairing code. Run adb pair TV_IP:PAIRING_PORT using the values shown in that dialog. Enter the six-digit code when asked.
  3. Run adb connect TV_IP:CONNECTION_PORT using IP address & port on the main Wireless debugging screen. The connection port can differ from the pairing port. For older Network debugging setups, skip pairing and connect with the port the TV uses, usually 5555.
  4. Check adb devices for the TV marked device, then run adb -s TV_IP:CONNECTION_PORT install -r Streambert-TV-Fire-OS.apk with the address shown in that list.

Open Streambert and turn off debugging when you’re done.

Transfer the APK from an Android phone or USB drive

With an Android phone, you can transfer the APK using Send Files to TV. Install it on both devices, choose Receive on the TV and Send on the phone, then select the APK and your TV. On the TV, open the received APK from Downloads with a file manager that supports APK installation. If prompted, allow Install unknown apps for the file manager and turn that permission off afterward.

Try installing the APK from a USB drive if your TV has a USB port for storage and a file manager that can open APKs. Copy the APK to the drive, open it on the TV, and if prompted enable Install unknown apps for that file manager. Turn that permission off after installing. A USB debugging switch alone may leave network access unavailable.

For network setup, check that the TV and phone or computer are on the same home network, avoid guest Wi-Fi, and keep the pairing screen open while entering the code. Google’s ADB instructions

Fire TV (Fire OS)

Check Settings → My Fire TV → About. If it says Vega OS, use the Vega section.

Download kit with Fire TV instructions APK only Read the Fire TV checklist

Install free with the Fire TV remote

  1. Search the Amazon Appstore on the Fire TV for Downloader by AFTVnews and choose Get if available. Open it and enter otosanx.github.io/streambert-tv-guide/ in the address field. Select Fire TV (Fire OS) under Devices, then choose APK only.
  2. If asked, allow Downloader under Settings → My Fire TV → Developer Options → Install unknown apps. If Developer Options is hidden, highlight your device name under About, press Select seven times, then go back. Older software may call the permission Apps from Unknown Sources.
  3. Go back to Downloader, reopen the downloaded APK if needed, and select Install. Turn off the install permission after setup. Open Streambert from Your Apps & Channels or Settings → Applications → Manage Installed Applications → Streambert → Launch application, then follow TMDB setup.
Downloader is unavailable. Install free from a computer
  1. Download Google Platform-Tools, extract the files, put the APK in that folder, and open a terminal there. Use .\adb on Windows PowerShell or ./adb on macOS or Linux.
  2. On Fire TV, turn on My Fire TV → Developer Options → ADB Debugging and follow any install permission prompt. Find its IP address under My Fire TV → About → Network. Put the computer on the same home network.
  3. Run adb connect FIRE_TV_IP:5555 with the Fire TV’s IP. Accept the prompt on the TV. Check adb devices for the Fire TV marked device, then run adb -s FIRE_TV_IP:5555 install -r Streambert-TV-Fire-OS.apk. Turn off debugging when done.

Developer preview

Roku TV

The Roku preview can browse and search TMDB and play direct HTTPS HLS or MP4 links. Streambert’s embedded web players are unavailable on Roku. The package compiled successfully. Older Roku models still need testing.

Download Roku ZIP Read the Roku guide
  1. Check your Roku and enable the installer. Note the model and software version under Settings → System → About. With the Roku remote, press Home three times, Up twice, then Right, Left, Right, Left, Right. Write down the address shown, enable the installer, accept Roku’s terms, and set a developer password. Let the Roku restart.
  2. Open the address in a browser. Use a phone or computer on the same home network. Type the local address in the browser’s address bar and include http:// if shown. Sign in as rokudev using the developer password you chose. If the phone browser can’t reach the installer, try a computer on the same network.
  3. Upload the ZIP as-is. Tap Upload, choose the original Roku ZIP, then tap Install. Roku has one developer-app slot, so this replaces any previously sideloaded preview.
  4. Connect the catalog. Follow TMDB setup. On Roku, choose TMDB token, enter the long token in the Roku keyboard, and select Continue. Try Trending and Search. To test video, use Open video URL with a direct HTTPS HLS or MP4 link you have permission to play. Direct links work without a TMDB token.

Set up TMDB once

The Movie Database at themoviedb.org provides titles, artwork, and search results. TMDB offers free API access for personal, non-commercial use with attribution. The token enables the catalog. It does not provide movies or subscription access.

  1. Create a free account. Go to TMDB signup and verify your email if prompted, or sign in to your existing account.
  2. Request free personal API access. Scan the QR or open Settings → API. If you don’t have access yet, select the request link and choose Personal use only (the developer or non-commercial option if the label differs). Accept the terms, fill out the applicable required fields, and submit. For a description, you can write “Personal use of the Streambert TV catalog to browse and search movie and TV metadata.” If the request form is difficult to use on a phone, open it on a computer.
  3. Copy the API Read Access Token. Return to Settings → API and copy the entire long token, which typically begins with eyJ. The short API Key shown on the same page is a different credential. Keep the token private. You can use the same token on your own TVs.
  4. Enter it in Streambert. Select the token field on the TV. For Android or Google TV, try the keyboard in the free Google TV phone remote. For Fire OS, try the free Amazon Fire TV phone remote. If the keyboard offers paste, paste the token there. Otherwise use the TV keyboard or a physical keyboard where supported. Choose Save and continue on Android TV or Fire OS. On Roku, use TMDB token → Continue and try the Roku phone remote’s keyboard if it’s offered.

To pair a phone remote, put the phone and TV on the same Wi-Fi, select your TV in the remote app, and enter the code shown on the TV if prompted. Open the token field on the TV to bring up text entry.

Troubleshooting

My phone can’t find the TV

Check that both devices are on the same home network. Guest networks can isolate devices. Confirm debugging is on and try entering the TV’s network address directly.

Do I need atvTools?

Use the free options above for installation and token entry. atvTools is an optional alternative. It is a paid app on iPhone. The Android version has ads and an optional premium unlock.

The TV says the file can’t be installed

Check the TV’s operating system and use its matching file. Fire OS needs the extracted APK. Roku’s developer installer needs the original Roku ZIP. If Android reports a signing conflict, save your settings before removing the older copy.

Streambert rejected my TMDB token

Open TMDB Settings → API and copy the entire API Read Access Token again. Make sure the TV has internet access. If your Roku accepts the token but playback doesn’t start when you browse a title, use Open video URL for direct playback. Roku’s catalog is a browsing and search preview.

The regular player didn’t start the next episode

In Streambert settings, enable Autoplay Next Episode and set Countdown Duration above zero. Start a regular TV episode with another aired episode in the same season and let it finish. Autoplay needs the playback source to expose the end of the video. Press Back during the countdown to cancel.
