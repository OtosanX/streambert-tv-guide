INSTALL STREAMBERT ON ANDROID TV OR GOOGLE TV

Use Streambert-TV-Fire-OS.apk. The shared APK works on NVIDIA Shield
running Android TV and is also packaged for Fire OS. Other Android TV
models may have different settings. The APK is installed on the TV.

FREE INSTALL WITH YOUR TV REMOTE

1. On the TV, install Downloader by AFTVnews from Google Play if
   available. Open it and enter otosanx.github.io/streambert-tv-guide/
   in its address field. Choose Install on Android TV > Download APK only.
2. Open the downloaded APK. If asked, allow Install unknown apps for
   Downloader in Settings, then return to Downloader and choose Install.
   You can turn the permission off after installing.
3. Open Streambert from Apps, or look in Settings > Apps > See all apps
   > Streambert > Open. Follow Start-here-TMDB.txt for free catalog setup
   and phone keyboard instructions.

TEST NEXT-EPISODE AUTOPLAY

In Streambert settings, turn on Autoplay Next Episode and set Countdown
Duration above zero. Choose a regular TV episode with another aired
episode in the same season. Seek near the end and let the episode finish.
The next episode should open after the countdown. Press Back during
the countdown to cancel. This was confirmed on NVIDIA Shield.

ANIME PLAYER CONTROLS

Show the player controls and select SUB or DUB beside Captions and
Settings to switch audio. Press Back to close the server menu and
return focus to Server Selection. Both were tested on NVIDIA Shield.

FREE COMPUTER INSTALL

Download and extract Google's Platform-Tools:
https://developer.android.com/tools/releases/platform-tools
Put the APK in the platform-tools folder. Open a terminal there.
In Windows PowerShell replace adb with .\adb. On macOS/Linux use ./adb
if adb is outside your PATH.

- On Google TV go to Settings > System > About. On Android TV, look
  under Settings > Device Preferences > About. Highlight Android TV
  OS build or Build, press the center button seven times, then go back
  to Developer options. Enable Wireless debugging or Network debugging.
  Put the TV and computer on the same home network.
- Wireless debugging: open Pair device with pairing code on the TV
  and run adb pair TV_IP:PAIRING_PORT with the address shown in that
  dialog. Enter the six-digit pairing code at the prompt.
- Run adb connect TV_IP:CONNECTION_PORT with the address and port on the
  main Wireless debugging screen. This port can differ from the
  pairing port. Older Network debugging skips pairing and typically
  uses 5555, or the port shown by the TV.
- Run adb devices. When your TV appears with status device, run
  adb -s TV_IP:CONNECTION_PORT install -r Streambert-TV-Fire-OS.apk
  using the exact TV address and port shown in the list.
- Open Streambert and turn off debugging when you are done.

IF THE TV DOESN'T CONNECT

- Check the home network, avoid guest Wi-Fi, and make sure the pairing
  code hasn't expired. USB debugging alone may not allow Wi-Fi access.
- For a phone-only fallback with an Android phone, install Send Files
  to TV on the TV and phone. Choose Receive on the TV, Send on the
  phone, then select the APK and TV. Open the APK in Downloads on the
  TV with a file manager that can open APKs. If prompted, grant Install
  unknown apps to that file manager and turn it off after installing.
  https://play.google.com/store/apps/details?id=com.yablio.sendfilestotv
- If your TV supports USB storage and has a file manager that can open
  APKs, copy the APK to a USB drive and open it on the TV. If prompted,
  grant Install unknown apps to that file manager for the installation
  and turn the permission off afterward.
- If the TV reports an existing-app signing conflict, keep the old
  install until you understand what will be lost. Removing the old
  copy can erase its settings and history.
