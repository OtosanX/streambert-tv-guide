INSTALL STREAMBERT ON FIRE TV FOR FREE

On the TV, check Settings > My Fire TV > About. Some models call this
menu Device & Software. This guide is for Fire OS. For Vega OS or
other TV systems, see the device list on the website. Android TV and
Google TV users can open Start-here-Android-TV.txt in this kit.

INSTALL WITH THE FIRE TV REMOTE

1. Search the Amazon Appstore on the Fire TV for Downloader by
   AFTVnews and choose Get if available. Open Downloader.
2. Enter otosanx.github.io/streambert-tv-guide/ in its address field.
   Under Devices, select Fire TV (Fire OS), then choose APK only.
3. If prompted, open Settings > My Fire TV > Developer Options >
   Install unknown apps and allow Downloader. On older models this
   may be called Apps from Unknown Sources. If Developer Options is
   hidden, go to About, highlight your Fire TV name, press the center
   button seven times, then go back.
4. Return to Downloader, reopen the APK if needed, and choose Install.
   You can turn off Downloader's install permission afterward.
5. Open Streambert from Your Apps & Channels. If needed, go to
   Settings > Applications > Manage Installed Applications >
   Streambert > Launch application. Follow Start-here-TMDB.txt for the
   free personal token and the Amazon Fire TV phone keyboard option.

FREE COMPUTER INSTALL IF DOWNLOADER IS UNAVAILABLE

1. Download and extract Google Platform-Tools:
   https://developer.android.com/tools/releases/platform-tools
   Put Streambert-TV-Fire-OS.apk in the platform-tools folder and open
   a terminal there. Replace adb with .\adb on Windows PowerShell or
   ./adb on macOS/Linux.
2. Connect the computer and Fire TV to the same home network.
   Turn on Settings > My Fire TV > Developer Options > ADB Debugging
   and follow any install permission prompt. Find the Fire TV IP
   address under Settings > My Fire TV > About > Network.
3. Run adb connect FIRE_TV_IP:5555 with the address from the TV and
   accept the debugging prompt on the TV. Run adb devices and check
   that the Fire TV is marked device.
4. Run adb -s FIRE_TV_IP:5555 install -r Streambert-TV-Fire-OS.apk
   with the same address. Open Streambert and turn off debugging.
   If the TV reports a signature conflict with an older copy, removing
   the old app can erase its settings and history.

atvTools is optional. Its iPhone app is paid. The Android version has
ads and an optional premium unlock.

The shared APK was tested on NVIDIA Shield. Fire OS playback still
needs a device test.
